跨境电商全链路演示

一个虚构的跨境品牌，从后台到前台完整跑通：多平台订单、海外仓库存、物流轨迹、多币种利润。后端基于 Supabase，数据每天自动重置。

本演示的代码、数据与设计均在 AI（Claude Code）辅助下完成

技术亮点

  • 安全的 AI 工具调用只读工具在服务端以访客身份执行（遵守 RLS），写操作只生成提案，确认后才执行；每访客每日配额。
  • 自带模型，不占额度可切换 DeepSeek、通义、Kimi、智谱、豆包、Claude、Gemini 等 OpenAI 兼容服务；Key 只存在浏览器、经服务端转发，不落库。
  • 采集 → 上架全链路插件读取页面内嵌数据，限速采集、遇验证暂停交给用户；ERP 里事务内生成 SPU + SKU，AI 翻译商品名、规格与描述。
  • 无服务器 + 零成本运维Supabase（Postgres、RLS、Edge Functions、Storage、pg_cron）+ GitHub Pages，数据每天 03:00 自动重置。
